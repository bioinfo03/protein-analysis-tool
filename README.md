# Protein Motif & Hydropathy Analyzer

A Flask web application that, given an **NCBI protein accession number** or a **protein sequence**,
reports every **`AL???LW`** motif that lies inside a **high-hydrophobicity window**, as defined by the
Kyte–Doolittle scale with a window size of **19** and a threshold of **1.6**. Each `?` is one of the 16
residues `A V L I M P F Y W S T N C H Q G`.

## What the output page contains

The numbers below follow the "HTML output page" list in the problem description.

| # | Requirement | Where it is |
|---|---|---|
| 1 | Link to NCBI's search result page (accession input) | **NCBI record** button (`https://www.ncbi.nlm.nih.gov/protein/?term=<accession>`) |
| 2 | Export NCBI's protein details view to Excel, with no HTML or junk | **Export to Excel** button |
| 3 | Hydrophobicity prediction plot (TMpred) | **Hydropathy profile**: generated by the app (see the note on TMpred below) |
| 4 | Kyte–Doolittle score plot for the high window containing the motif | **Motif score plots**: one per motif, marked *Passes* or *Below threshold* |
| 5 | Sequence with the motif in **blue** and high-KD residues in **red** | **Sequence** |

Extras suggested in the brief and added here:

- A single page: results appear below the input box without reloading.
- One input box: the app works out whether you typed an accession or pasted a sequence.
- A user-defined **motif pattern** (`?`, letters and `[ILV]` groups), set of **allowed residues**, **window size** and **threshold**.
- Every motif occurrence is shown, including the ones that fail, with the best window score for each.
- An Excel export of the analysis for pasted sequences, and analysis sheets in the NCBI export.
- Interactive charts with hover details, plus PNG download.
- Copy as FASTA, and a print layout.
- Friendly error messages: unknown accession, DNA pasted by mistake, NCBI down, and so on.

## Method

1. **Sequence.** For an accession, the record is fetched with NCBI E-utilities
   (`efetch.fcgi?db=protein&rettype=gp`). This returns the same GenPept text as NCBI's details view,
   and the sequence is read from its `ORIGIN` section. For pasted input, FASTA headers, whitespace and
   position numbers are removed.
2. **Hydropathy.** Each residue gets its Kyte–Doolittle value, from −4.5 (R) to +4.5 (I).
   For every complete window of *w* residues starting at residue *i*, the mean score is plotted at the
   window centre, *i* + (*w*−1)/2. With *w* = 19 that is residue *i* + 9.
3. **Motif.** The pattern is turned into a regular expression,
   `AL[AVLIMPFYWSTNCHQG]{3}LW`, and searched with a look-ahead so that overlapping matches are found too.
4. **Qualifying rule.** A motif is *in a high-hydrophobicity window* when at least one complete
   window with a mean score of at least 1.6 contains all of its residues. Each motif's plot shows
   every window that contains the motif, which is 13 windows for a 7-residue motif and *w* = 19.
5. **Highlighting.** Motif residues are blue. A residue is red when the window centred on it passes
   the threshold, as in the example output.

**Check against the brief.** The 481-residue example protein in the problem description gives the
same 13 scores as the example plot (0.36, 0.49, 0.72 … 1.81 around `ALHAGLW` 297–303). The example
labels each point one residue later than the window midpoint, so this tool follows the textbook
convention of plotting at the centre. The example protein can be loaded with one click on the input page.

**TMpred.** The brief suggests taking the plot from TMpred (`ch.embnet.org`), but that service is no
longer online. The brief also says it "would be great" to generate the plot yourself, so the app draws
a full-length hydropathy profile and links to current transmembrane predictors (DeepTMHMM, Phobius,
TMHMM 2.0) for comparison.


## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py               # http://127.0.0.1:5000   (PORT=8000 python app.py to change the port)
```

Production-style:

```bash
gunicorn app:app --workers 2 --timeout 60
```

Optional environment variables: `NCBI_EMAIL` and `NCBI_API_KEY` are sent to NCBI as its usage policy
recommends. An API key raises NCBI's rate limit from 3 to 10 requests per second.

## Deploy to Vercel

Vercel detects the Flask `app` in `app.py` and runs it as a Python function with no build step.
Files in `public/` are served from Vercel's CDN, which is why the stylesheet and scripts live in
`public/static/`. Flask serves the same `/static/...` URLs when the app runs locally.

1. Push this folder to a GitHub repository.
2. On vercel.com: **Add New → Project**, import the repository, and press **Deploy**. No settings need changing.
3. Optional: under **Settings → Environment Variables**, add `NCBI_API_KEY`, a free key from your NCBI
   account. It raises NCBI's rate limit, which helps because Vercel shares outgoing IP addresses.

## Tests

```bash
pip install -r requirements-dev.txt
pytest
```

The tests cover the scoring (against the assignment's example plot), the motif rules, the input
cleaning, the GenPept parsing, every route, and the contents of the Excel files.

## Try it

The chips under the input box run these examples:

- **Semaphorin-7A** (O75326, human): `ALAASLW` at 646–652, inside a hydrophobic window.
- **Ammonium transporter** (P69681, *E. coli* AmtB): `ALVCILW` at 75–81, inside a hydrophobic window.
- **Assignment example**: the 481-residue protein from the brief's example output. `ALHAGLW` (297–303) and `ALIALLW` (238–244) both qualify.

The motif is rare. A scan of the ~25,000 reviewed human and *E. coli* proteins in UniProt found it inside a
hydrophobic window in only 41. **Q26473**, the accession the brief uses to illustrate the NCBI lookup and
the Excel format, has no `AL???LW` at all. The page says so, and its Excel export still demonstrates
requirement 2.

## Limitations

- High hydrophobicity suggests a membrane-spanning region but does not prove one. Dedicated predictors
  (DeepTMHMM, Phobius) model the topology more accurately.
- The accession lookup needs internet access to NCBI.
